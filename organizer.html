🎲 Жеребьёвка

Страница для организатора. Жеребьёвка проходит прямо в браузере. Ты увидишь только коды участников, а пары «кто кому» не покажутся никому, включая тебя.

Не вводи чужие коды, иначе сам станешь тем, кто знает пары. Раздай каждому его код лично. Если перезапустить жеребьёвку, старые коды перестанут работать.
УчастникКод

Что дальше:

  1. Скачай draw.json и замени им файл в репозитории (рядом с index.html).
  2. Закоммить и запушь. Через минуту-две GitHub Pages обновится.
  3. Раздай коды: каждому только его строку.
  4. Участник открывает главную страницу, вводит код и видит своего получателя.
